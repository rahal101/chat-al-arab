# شات العرب v6

نسخة تجهيز للإطلاق من مشروع شات العرب.

## الجديد
- تسجيل حساب ودخول بالبريد أو اسم المستخدم.
- كلمات مرور مشفرة باستخدام bcryptjs.
- JWT للجلسات.
- PostgreSQL لحفظ الحسابات والملفات الشخصية والبلاغات والحظر.
- حماية HTTP عبر Helmet.
- Rate limiting لواجهات الحساب.
- أساس لنظام البلاغات والحظر.
- Socket.IO للدردشة الفورية.
- غرف عامة/مصر/العرب.
- دردشة عشوائية.
- واجهة RTL متجاوبة.

## التشغيل
1. ثبت Node.js.
2. أنشئ قاعدة PostgreSQL.
3. نفذ `schema.sql`.
4. انسخ `.env.example` إلى `.env` واضبط `DATABASE_URL` و `JWT_SECRET`.
5. نفذ:
   `npm install`
   `npm start`
6. افتح:
   `http://localhost:3000`

## قبل النشر العام
- استخدم HTTPS.
- استخدم TURN Server للصوت في WebRTC.
- ضع JWT_SECRET قوي وفريد.
- شغل PostgreSQL ببيانات اعتماد منفصلة.
- أضف reverse proxy مثل Nginx.
- راجع سياسات الخصوصية وشروط الاستخدام ونظام الإشراف قبل فتح الموقع للجمهور.

ملاحظة: نسخة v6 هي أساس إطلاق وليست تدقيقاً أمنياً نهائياً.
